# Third-Party Materials and Licensing

This repository is an educational guide; **it does not currently bundle redistributed third-party art, proprietary Unreal Engine source, vendor plugins, commercial audio, third-party sample-game source or AI-generated assets**.

The following products are discussed as production tools or references, **not included as redistributable components**:

| Product or service | Use discussed | Redistribution policy |
| --- | --- | --- |
| Unreal Engine and Unreal Engine tools | Engine, Editor, gameplay, rendering and packaging | Epic's applicable EULA and trademark guidelines; no Engine source is bundled |
| Blender | 3D modeling, animation, Python automation | Blender's own licenses apply to the software; user-created outputs retain their applicable rights |
| Codex, Claude and Gemini/Antigravity | Optional coding, documentation and asset operators | Provider terms and output rights must be checked for each use |
| Tripo and Meshy | Optional 3D generation | Asset/output licensing and plan restrictions require per-asset verification |
| Third-party reference images, sounds, fonts, plugins or textures | Visual and production references | Do not redistribute without an appropriate license or permission |

**Asset provenance record:** source/provider, original author where known, tool/model/version, prompt reference if AI-generated, generation or acquisition date, original file, export, checksum when used, permission/license basis, permitted redistribution scope, credited attribution, import location, and proof of in-game validation.

Never treat “free download”, “AI-generated”, “available in Fab”, “present in a screenshot”, or “uploaded to a private repository” as proof of permission to redistribute here.

Case studies may describe private source artifacts and cite non-sensitive relative names, but **they do not copy or relicense the source repository**. Where evidence cannot legally be shown, describe the verification limits without fabricating substitute images or logs.

Third-party additions must update this document with precise license and attribution details before public publication.
