## Known boundaries preserved for future technical validation

- T05 Light Character's in-session authority and T07 durable Run Subsystem must be reconciled by a real integrated game project, not used as independent competing authorities.
- Real input/interaction actors, authored UMG widgets, an actual map/world rehydration coordinator and a working Continue path require true Unreal project integration.
- Cinematic, audio, Niagara, Chaos, packaged Windows release and human playtest require real UE Editor assets and executable observations.
- Exact version-sensitive APIs and external documentation must be verified against the **installed Engine 5.9 build**; the Epic documentation website may default to a different documentation version.
- Historical case-study grades are evidence-specific; an agent implementation report cannot be upgraded to human acceptance or a shipped artifact without corresponding proof.

- **v1.0.0** means the initial **documentation content scope** is complete and publicly indexed. It is not a statement that every reader has executed all tutorial steps.
- Editorial corrections that do not redefine tutorial requirements can use **1.0.x**. New backwards-compatible tutorial sections/templates can use **1.x**. Material changes to the overall production contract can use **2.x**.
